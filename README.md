This is a faithful port of PHPRetro to MySQLi that works on the latest versions of PHP.
There are a few known issues

- PHP 8.2 throws a couple of errors here and there - will look into it.
- Avatar Wardrobe dosen't save looks.
- MUS Commands to the emulator aren't finished.
- Group Pages throw errors in all php versions.

I'll fix these in due time - other than that I believe everything works as it did back in 2009.
